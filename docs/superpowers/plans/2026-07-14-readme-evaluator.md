# 문서 개편 작업 참고 기록

이 경로의 이전 README 작업 계획은 현재 적용되지 않습니다. 실행할 task나 에이전트 지시가 아니며, 이전 링크를 유지하는 참고 페이지입니다.

## 현재 문서 관리 위치

[루트 README](../../../README.md)는 프로젝트 소개·기능·사용 흐름·기술·구조·문서 안내·원본 저장소 순서로 구성합니다. 환경·API·DB·모델·운영 세부 내용은 [개발 문서](../../README.md)에 둡니다.

기존 기술 설명은 현재 소스와 대조해 각 분류에 통합했습니다. 저장된 모델 지표는 [오프라인 평가](../../07-ai-modeling/offline-evaluation.md)에, 검증 명령과 미확인 사항은 [품질 문서](../../10-quality/verification-and-limitations.md)에 있습니다.

문서 수정 시 실제 파일 링크와 계약을 확인하고, 테스트를 실행하지 않았으면 통과 결과로 적지 않습니다. 과거 계획 문구보다 현재 코드와 해당 개발 문서를 기준으로 읽습니다.
